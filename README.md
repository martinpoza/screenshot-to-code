# Screenshot to Code

Turn a screenshot of any user interface into a working React component, using a free AI model that runs locally on your own computer with [Ollama](https://ollama.com).

> 🚧 Work in progress. I'm building this step by step while learning to code.

## How it will work

```
screenshot.png
   ↓  AI step 1: describe the layout as JSON
   ↓  AI step 2: turn the JSON into a React component
   ↓  AI step 3: check the code for errors
Component.tsx
```
